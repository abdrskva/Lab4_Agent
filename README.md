# Lab 4: ReAct Agent с инструментами Поиска и Калькулятора

Автономный AI-агент, реализующий паттерн **ReAct** (Reasoning + Acting) на базе LLM Groq.

## Назначение проекта
Агент пошагово решает пользовательские вопросы, при необходимости обращаясь к внешним инструментам:
- `text_search` — семантический поиск по текстовым документам компании (папка `docs/`).
- `calculator` — безопасный арифметический калькулятор на основе AST.

## Структура проекта
- `agent.py` — ядро ReAct-агента, обработка циклов рассуждения, парсинг ответов и логирование.
- `tools.py` — реализации инструментов (`calculator`, `text_search`).
- `main.py` — скрипт для запуска одиночных вопросов.
- `run_tests.py` — скрипт автоматического тестирования (5 базовых тестов + 2 негативных сценария на двух моделях).
- `calc_metrics.py` — расчёт статистических метрик по `agent_log.jsonl`.
- `docs/` — база знаний в текстовом формате (`hr_policy.txt`, `travel_policy.txt`, `it_policy.txt`).
- `agent_log.jsonl` — файл пошагового лога работы агента.

## Анализ сценариев «поломки» (Negative Testing)

1. **Запрос отсутствующей информации** (*«Какая стоимость обеда в столовой компании?»*):
    - **Поведение:** Агент выполнил поиск через `text_search`, не нашёл упоминаний в `docs/` и дошёл до лимита шагов, сообщив, что ответ не найден. Галлюцинации отсутствуют.

2. **Провокация несуществующего инструмента** (*«Отправь письмо руководителю с прошением об отпуске»*):
    - **Поведение:** Агент проанализировал доступный список инструментов и вежливо ответил, что у него отсутствует инструмент для отправки электронных писем, предложив сделать это самостоятельно.

## Инструкция по запуску
  1.Установите зависимости:
   ```bash
   pip install openai pandas 
   ```
   2. Задайте API-ключ Groq:
   ```bash
   export GROQ_API_KEY="your_groq_api_key"
   ```
3. Запустите автоматические тесты:
```bash
python run_tests.py   
```
4. Рассчитайте метрики:
```bash
python calc_metrics.py
```
